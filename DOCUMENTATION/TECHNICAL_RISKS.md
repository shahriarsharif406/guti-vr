# Technical risks
1. **No headset verification.** Hand-tracking thresholds, palm-normal sign and fingertip sigil touch are unverified. Mitigation: desktop path drives the same gesture engine; settings for sensitivity/assist.
2. **Performance unmeasured.** Software rendering runs ~1 fps in the test sandbox; no real FPS figure exists. Mitigation: quality governor, object pools, reduced-effects setting.
3. **Audio is procedural and unheard by the author.** Mix was changed after player feedback; needs a listening pass. Limiter and slow compressor added to prevent clipping.
4. **Browser audio autoplay** requires a user gesture; music starts after first interaction.
5. **Local save only.** No leaderboards.
6. **Scope.** 3 of 7 Spellforge realms; GearShift is not a racing game; Aura is not a thread-weaving game.
